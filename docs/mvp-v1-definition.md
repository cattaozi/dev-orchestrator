# MVP V1 定义（个人 AI IDE）

## 一、MVP 目标

在 2~4 周内验证：  
**个人用户是否愿意用本产品作为“每日开发工作台”，而不仅仅是临时聊天工具。**

## 二、功能范围（In Scope）

1. 项目（文件夹）管理
- 新增/编辑/删除项目（`local_path` 为核心字段）
- 项目运行面板（受控服务定义、启动、停止、重启、状态）

2. 任务管理（轻量）
- 每个项目下创建任务
- 任务状态流转：`todo -> doing -> done`（可加 `blocked`）
- 任务与 Session 绑定

3. Session 管理
- 按项目/任务发起 Session
- Session 输出展示（以“结果说明”为主）
- Session 自动总结：做了什么、涉及哪些文件、下一步建议

4. Dashboard 总览
- 跨项目状态一屏可见
- 今日推进指标
- 阻塞/异常提示

## 三、非目标（Out of Scope）

- 复杂 PRD 生命周期（评审、版本流转）
- 多角色权限体系与审批流
- 企业级审计与成本中心
- 自研对话模型层（不与原生客户端争聊天体验）

## 四、关键体验要求

- 首屏 10 秒内回答三个问题：  
  - 我现在做什么？  
  - 哪些项目在运行？  
  - 哪个任务卡住了？
- 配置动作（如新增服务）默认收纳，不干扰主流程。
- 状态表达优先用颜色/结构，不堆文案标签。

## 五、MVP 数据最小闭环

- `Project` 1:N `Task`
- `Task` 1:N `Session`
- `Project` 1:N `ProjectService`
- `Session` 产生 `SessionSummary`（可从事件流提炼）

## 六、验收标准

- 每个项目可稳定管理多个服务。
- Dashboard 指标可实时反映项目状态与任务推进。
- 每次 Session 结束后，用户无需翻日志即可理解结果与下一步。
