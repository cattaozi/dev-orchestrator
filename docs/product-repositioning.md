# 产品重定位（个人 AI IDE）

## 一、背景

当前形态与原生 AI 客户端（Codex/OpenCode/Claude Code UI）在对话体验上高度重叠，难以建立长期差异化。  
若继续沿“聊天壳 + 流程概念堆叠”方向迭代，边际价值会快速下降。

## 二、新定位

**产品定位**：以“本地项目文件夹”为单位的个人 AI IDE 控制台。  
**核心目标**：降低上下文切换成本，持续推进任务闭环，而不是提升聊天本身体验。

## 三、核心对象（仅保留 3 个）

1. `项目（Project）`：一个本地文件夹（不是仓库）。
2. `任务（Task）`：用户当前需要推进的一件事。
3. `会话（Session）`：一次 AI 执行过程（可继续、可回放、可总结）。

## 四、价值主张

相较原生客户端，本产品提供的是“个人管理价值”而非“对话价值”：

- 跨项目总览：知道今天推进了什么、卡在哪里。
- 运行面板：一键启动/停止项目服务，状态可见。
- 会话结果沉淀：保留“产出摘要”而非长聊天噪音。
- 任务推进闭环：从想法到执行到结果的连续流。

## 五、设计原则

- 轻流程：不强制 PRD、审批、多人角色。
- 高信噪：优先显示结果、状态、下一步，不展示冗余系统细节。
- 低心智负担：经常用的前置，低频配置收纳到弹窗/二级菜单。
- 可恢复：中断后能快速找回工作上下文。

## 六、成功判定（产品层）

- 用户每天打开 Dashboard 能立刻知道“现在该做什么”。
- 单日内跨项目切换成本明显下降。
- Session 结果可直接转化为任务推进，而不是停留在对话记录中。
