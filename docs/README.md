# 个人 AI IDE 重规划文档

本目录用于承接产品路线调整后的设计文档（以 `项目 / 任务 / Session` 三核心概念为中心）。

## 文档列表

- `product-repositioning.md`：产品重定位与价值主张
- `mvp-v1-definition.md`：MVP 目标、范围、非目标
- `information-architecture.md`：信息架构与核心流程
- `dashboard-metrics-v1.md`：Dashboard 指标体系（V1）
- `delivery-roadmap-v1.md`：两阶段交付路线与验收

## 评审顺序（建议）

1. 先看 `product-repositioning.md`（方向）
2. 再看 `mvp-v1-definition.md`（做什么/不做什么）
3. 再看 `information-architecture.md`（怎么落到页面）
4. 最后看 `dashboard-metrics-v1.md` + `delivery-roadmap-v1.md`（如何执行）
